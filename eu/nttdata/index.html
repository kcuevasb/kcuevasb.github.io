5@RestController

7public class EsperientziaController {
8
9    private static final Logger LOG =
10            LoggerFactory.getLogger(EsperientziaController.class);
11
12    @Autowired
13    private IkasitakoaRepository repository;
14
15    @Autowired
16    private WsSisnetClient wsSisnet;   // SOAP, IMQ
17
18    @PostMapping("/proiektuak")
19    @Transactional
20    public List<Ikasitakoa> lanEgin(@RequestBody BezeroInput bezeroa) {
21
22        LOG.info("Proiektu berria {}(r)entzat", bezeroa.getBezeroa());
23
24        if (bezeroa.usa(Integrazioa.SOAP)) {
25            wsSisnet.validarConexion();
26        }
27
28        // Sartzen dena bezero bat da; gelditzen dena ikasitakoa.
29        return repository.saveAll(Ikasitakoa.de(bezeroa));
30    }
31}

# Bezeroak eta proiektuak

Bost urte, bost proiektu. Ia dena osasungintza — non bug bat ez den intzidentzia bat, heltzen ez den errezeta bat baizik.

Bitartekarien Ataria IMQ

Aplikazioaren analisia eta garapena hutsetik. Etapako modernoena.

Java 11 · Spring Boot 2.3 · HATEOAS · JPA · QueryDSL · Hibernate · API REST · SOAP · Azure · PostgreSQL

Errezeta Digitala IMQ

Garapena eta mantentzea, baita hedapenen kudeaketa eta exekuzioa ere hainbat ingurunetan. Etapa osoaren oinarria jarri zuen proiektua da: mikrozerbitzuak, REST APIak, Azure API Management eta datu-base erlazionala.

Java 8 · Spring Boot 2.1 · HATEOAS · JPA · QueryDSL · Hibernate · API REST · SOAP · Azure · Oracle · PL/SQL · SVN

Asistentzia Nukleoa IMQ

Hobekuntza funtzionalak eta intzidentzien konponketa asistentzia nukleoan.

J2EE · Hibernate · Spring · ZK · QueryDSL · Oracle · Tomcat 7

Ospitale kudeaketa H. U. Marqués de Valdecilla

Hobekuntzak eta intzidentzien konponketa ospitaleko arlo ez-klinikoen kudeaketan, baita hedapenak ere hainbat ingurunetan.
