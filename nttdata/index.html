5@RestController
6@RequestMapping("/api/nttdata/experiencia")
7public class ExperienciaController {
8
9    private static final Logger LOG =
10            LoggerFactory.getLogger(ExperienciaController.class);
11
12    @Autowired
13    private AprendizajeRepository repository;
14
15    @Autowired
16    private WsSisnetClient wsSisnet;   // SOAP, IMQ
17
18    @PostMapping("/proyectos")
19    @Transactional
20    public List<Aprendizaje> trabajar(@RequestBody ClienteInput cliente) {
21
22        LOG.info("Nuevo proyecto para {}", cliente.getCliente());
23
24        if (cliente.usa(Integracion.SOAP)) {
25            wsSisnet.validarConexion();
26        }
27
28        // Lo que entra es un cliente; lo que queda es lo aprendido.
29        return repository.saveAll(Aprendizaje.de(cliente));
30    }
31}

# Clientes y proyectos

Cinco años, cinco proyectos. Casi todo sanidad — donde un bug no es una incidencia, es una receta que no llega.

Portal de Mediadores IMQ

Análisis y desarrollo de la aplicación desde cero. La más moderna de la etapa.

Java 11 · Spring Boot 2.3 · HATEOAS · JPA · QueryDSL · Hibernate · API REST · SOAP · Azure · PostgreSQL

Prescripción Digital IMQ

Desarrollo y mantenimiento. Además, gestión y ejecución de los despliegues en los distintos entornos.

Java 8 · Spring Boot 2.1 · HATEOAS · JPA · QueryDSL · Hibernate · API REST · SOAP · Azure · Oracle · PL/SQL · SVN

Core Asistencial IMQ

Mejoras funcionales y resolución de incidencias sobre el núcleo asistencial.

J2EE · Hibernate · Spring · ZK · QueryDSL · Oracle · Tomcat 7

Gestión hospitalaria H. U. Marqués de Valdecilla

Mejoras y resolución de incidencias en la gestión de las áreas no clínicas del hospital, más los despliegues en los distintos entornos.

J2EE · Hibernate · Spring · ZK · jQuery · Oracle · WebLogic 11g

Field Service Management Siemens-Gamesa

Análisis y parametrización de soluciones Field Service. El único proyecto de la etapa fuera de sanidad y fuera de Java.

Oracle Field Service Cloud (OFSC)
