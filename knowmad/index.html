3// El Corte Inglés — dominio de catálogo.
4// Aquí Kafka dejó de ser una línea del CV: un cambio de precio
5// se propaga sin que ningún servicio llame a otro.
6@Component
7@Slf4j
8@RequiredArgsConstructor
9public class CatalogoEventConsumer {
10
11    private final AprendizajeRepository aprendizajes;
12
13    @KafkaListener(topics = "catalogo.producto.actualizado",
14                   groupId = "catalogo-service")
15    public void onEvento(CatalogoEvent evento, Acknowledgment ack) {
16
17        log.info("Evento de {} para SKU {}",
18                 evento.cliente(), evento.sku());
19        try {
20            aprendizajes.saveAll(Aprendizaje.extraerDe(evento));
21            ack.acknowledge();          // commit manual del offset
22        } catch (Exception e) {
23            log.error("Fallo procesando {} → DLQ", evento.sku(), e);
24            throw e;
25        }
26    }
27}

# Clientes

Tres años de consultoría en dos clientes muy distintos.

El Corte Inglés ago 2023 – sep 2025

Análisis y desarrollo de microservicios backend con Spring Boot para el dominio de catálogo. Consultas a bases de datos no relacionales con MongoDB. Desarrollo de los servicios de comunicación entre microservicios y de agregación de datos, más soporte en el diseño de arquitectura del proyecto.

Despliegue con Jenkins y Clarive en distintos entornos, calidad con Sonar, tests con Mockito y JUnit, y eventos asíncronos con Kafka.

Java 11-17 · Spring Boot · MongoDB · Couchbase · Kafka · Docker · Kubernetes · Jenkins · Clarive · Kibana · Bitbucket · Sonar

BeeDigital nov 2022 – jul 2023

Análisis y desarrollo de microservicios backend con Spring Boot para el posicionamiento de empresas en internet. Consultas a DocumentDB y DynamoDB. Diseño de los servicios de comunicación entre microservicios y de agregación de datos, con control de versiones en repositorios Git de Amazon.

Despliegue con Jenkins, calidad con Sonar, tests con Mockito y JUnit, y eventos asíncronos con Kafka.

Java 19 · Spring Boot · AWS · DynamoDB · DocumentDB · Kafka · JWT · Jenkins · Sonar

# Knowmad Mood · nov 2022 – sep 2025

Tres años de consultoría en dos clientes: BeeDigital primero (posicionamiento de empresas en internet, sobre AWS) y El Corte Inglés después (el dominio de catálogo, MongoDB y mucho volumen).

La etapa anterior (NTT Data) y la actual (Sopra Steria) tienen su propio capítulo.
